**Context**: Individual managing personal finances through the bank

**Key Use Cases**:

- Dispute transactions or report fraud

- Get answers to product questions (fees, rates, terms)

**Agent Capabilities Required**:
- **Account Agent**: Real-time balance, transaction queries, statement generation
- **Payment Agent**: Transfers, bill pay, international payments
- **Lending Agent**: Product recommendations, pre-qualification, application processing
- **Advice Agent**: Spending insights, savings recommendations, financial planning
- **Service Agent**: Issue resolution, dispute handling, authentication

**Data Sources Accessed**:
- Core banking system (accounts, transactions)
- Customer profile (CRM)
- Credit bureau data
- Transaction categorization engine
- Product catalog
- Fraud detection system

**Transformation Outcome**:
- 24/7 self-service for 90% of queries
- Instant loan decisions (vs 3-5 days)
- Proactive advice (not reactive support)
- Zero wait times
- **Cost Saving**: Reduce branch/call center volume by 70%

## CROSS-CUTTING AGENT ARCHITECTURE

### Orchestration Layer
All personas access the same interface, but requests are intelligently routed to:
- **Context Engine**: Understands user role, current task, and data access rights
- **Agent Router**: Selects and coordinates appropriate specialist agents
- **Data Federation Layer**: Securely accesses only authorized data sources
- **Response Synthesizer**: Delivers results in persona-appropriate format

### Pre-Governed Control Plane
- Role-based access control (RBAC) enforced at agent level
- Audit trail of all queries and actions
- Data privacy and security controls
- Regulatory compliance built into every agent

### Key Differentiators
1. **No Manual Switching**: System knows who you are and what you need
2. **Horizontal Implementation**: Same architecture across all personas
3. **Rapid Deployment**: 4-8 weeks per persona/use case
4. **Composable**: Agents can be combined for complex workflows
5. **Scalable**: Add new personas without rebuilding core platform
